# 可以量度什麼 —— 候選清單與取捨

狀態：2026-10-25 · 對應 `rulebook.md` 與 §4 的六個 gate

**這份文件的作用**：把「一份簡報有什麼可以驗證」全部列出來，然後說明為什麼只有六條進了 metric。
寫論文時，這張表回答兩個問題：「你為什麼只做六條？」以及「你有沒有漏掉重要的？」

Legend：
`✅` 已實作 · `🔜` 已排程（P2）· `⚠️` 需要渲染，phase 2 · `❌` 語意判斷，屬人評 · `🚫` 不適合當 gate

## 取捨：為什麼只有六條入 metric

五個條件，全部要通過：

1. **可判定**：不需要參考 deck、不需要人手標註
2. **確定性**：同一份檔案跑兩次，答案一樣
3. **違規就是壞**：不是品味問題，是機械問題
4. **便宜**：可以在迴圈裡每次渲染後重跑（< 1 秒／頁）
5. **可解釋**：可以指出「哪個形狀、哪個值、哪個門檻」

通過的：

| Gate | 來自 | 為什麼不是候選清單裡的另一條 |
|---|---|---|
| G1 出界 | A1 | 最純粹的二元規則，無自由參數 |
| G2 重疊 | A2 | 純幾何，且幾乎必然是錯 |
| G3 字級 | B1 | 唯一有「後排看不到」這個物理後果的排版屬性 |
| G4 對比 | C1 | 唯一有正式標準（WCAG）的視覺屬性 |
| G5 溢出 | B7 | 純幾何的推論（估算高度），可驗證誤差 |
| G6 密度 | B5+B6 | 直接對應「一頁塞太多」這個最常被批評的失敗 |

**被剔除的代表，以及原因：**

- **A5 太貼邊**：與 G1 高度相關，加了只會令兩個 gate 講同一件事。
- **B2/B3 字級與字體種類**：風格問題，冇證據支持「多就是壞」。
- **C4 顏色數量**：同上。
- **D8–D12（離題、事實、拼字）**：需要語意，屬人評 —— 這是**範圍聲明的核心**：metric 只做機械可判的，其餘交人評。
- **F1/F2 字體替換**：依賴環境，同一份 deck 在不同機器會得到不同答案 —— 違反條件 2。

## 這份清單自己暴露了三個缺口

1. **G0 非空**：一張完全空白或壞掉的 slide，現在會通過 G1/G2/G3（冇東西可以違規），應該加一條 `non-empty`。
2. **A3 文字壓圖**：現在混在 G2 裡，但「字壓在圖上」與「字壓字」是兩種不同的失敗，值得分開。
3. **內容層完全空白**：這次修 parse 時發現的 `ing a slide deck from a document`、`Text Encoder Image Encoder` 這類**胡言亂語的 bullet**，六個 gate 一個都抓不到 —— 因為它們語法合法、長度正常、字級正確。這是 metric 的真實邊界，也是為什麼仍然需要人評與 LLM 層。
